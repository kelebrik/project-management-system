# Contributing

This repository is published for reading and copying the unmodified source.
Changes and derivative works are not permitted under the
[Project Management System Non-Commercial License](LICENSE).

Before opening a pull request:

1. Run `npm run typecheck`.
2. Run the relevant unit and integration tests.
3. Do not commit passwords, API tokens, database dumps, or private deployment
   configuration.
4. Keep Jira integration read-only. Never add Jira business-data writes.
