# Варианты страницы «Портфель» на A4

Все макеты отрисованы в формате A4 landscape, 1754×1240 px. В каждом используется один и тот же стресс-набор: 5 проектов, 25 целей, 10 блокирующих проблем и 20 ключевых рисков. Прокрутка, скрытые элементы и счетчики вида `+N` не используются.

Нижний раздел «Проекты» одинаков во всех пяти вариантах и сохраняет текущую структуру страницы.

Контроль текущего дизайна на том же наборе данных:

- `00-current-design-full.jpg` — полная естественная высота страницы с отмеченными границами листов A4.
- `00-current-design-a4-page-1.jpg` — содержимое, которое фактически попадает на первый лист A4 без изменения текущей верстки.

1. `01-urgency-board.jpg` — все элементы распределены по срочности. Для целей используется прогнозная дата; записи без даты вынесены отдельно.
2. `02-twin-ledgers.jpg` — цели и RAID показаны двумя параллельными плоскими реестрами. Рекомендуемый вариант для сравнения данных.
3. `03-time-first.jpg` — цели расположены на общей временной оси, проблемы и риски собраны в плотные реестры.
4. `04-project-columns.jpg` — одна вертикальная колонка на проект, внутри нее последовательно показаны цели, проблемы и риски.
5. `05-category-stack.jpg` — категории расположены уровнями; ширина каждого уровня соответствует объему данных.

Повторный рендер:

```bash
node docs/portfolio-a4-design/render-mockups.cjs
node docs/portfolio-a4-design/render-current-design.cjs
```
