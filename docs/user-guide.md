# Пользовательская документация

## Режим чтения

Без входа в систему доступны страницы просмотра:

- Портфель проектов;
- Обзор и вехи;
- Паспорт проекта;
- Структура;
- Гантт;
- Открытые вопросы;
- Риски и проблемы;
- Календари;
- Артефакты проекта;
- Закрытые проекты.

Редактирование требует входа в систему и соответствующих прав.

## Проекты

Проект выбирается в левой панели. Адреса страниц строятся по коду проекта:

- `/<код проекта>/overview`;
- `/<код проекта>/passport`;
- `/<код проекта>/wbs`;
- `/<код проекта>/gantt`;
- `/<код проекта>/open-issues`;
- `/<код проекта>/risks`;
- `/<код проекта>/calendars`;
- `/<код проекта>/artifacts`.

## Структура

Структура используется как мастер-план проекта:

- редактирование строк;
- изменение уровня вложенности;
- drag-and-drop строк;
- до шести предшественников;
- календарь RU/CN;
- Jira ticket link;
- undo/redo последних изменений;
- фильтр критического пути;
- разворачивание по уровням 1-5.

Enter сохраняет изменение ячейки, Escape отменяет.

## Гантт

Гантт показывает сроки, связи, вехи, текущую дату и режимы отображения:

- месяцы/кварталы;
- связи;
- критический путь;
- базовый план;
- прогноз;
- полноэкранный режим;
- графическое создание и изменение связей между задачами.

Если включен критический путь, остальные связи скрываются.

## Обзор и вехи

Страница предназначена для руководства:

- ключевые риски в красной зоне;
- тикеты под риском;
- решения по ключевым открытым вопросам;
- отклонение сроков;
- таймлайн вех;
- вехи по фазам;
- все вехи.

Ключевые риски и Jira-ключи кликабельны, если для записи задан URL.

## Открытые вопросы

Для создания открытого вопроса обязательно только поле `Заголовок`. Если срок переносится, система считает отставание в календарных днях относительно первоначального срока. Закрытые вопросы отображаются отдельно с отставанием на момент закрытия.

## Риски и проблемы

Реестр разделен на:

- риски;
- проблемы;
- допущения.

У записи можно вести историю статусов. Последний статус ключевого риска выводится на странице Обзор.
