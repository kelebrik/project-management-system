# Top-10 визуальных улучшений существующих страниц

Дата: 14.07.2026. Область: только визуальный дизайн и взаимодействие уже существующих страниц. Новые разделы и новые продуктовые функции не предлагаются.

## Направление

Интерфейс остается рабочим инструментом для PM и PMO: высокая плотность данных, спокойный фон, предсказуемая навигация и минимум декоративных контейнеров. Основной акцент меняется с синего на темный бирюзовый, а красный, янтарный и зеленый используются только как семантические статусы.

Два решения имеют повышенный объем реализации:

- двухуровневый верхний shell означает замену текущего бокового меню, а не только смену CSS;
- переход с синего action-цвета на бирюзовый является осознанной сменой основного визуального акцента во всей системе.

## Топ-10

| # | Доработка | Что меняется | Эффект |
|---|---|---|---|
| 1 | Ролевая палитра | Фон `#F4F6F7`, поверхности `#FFFFFF`, текст `#17212B`, action `#0F766E`; RAG-цвета не окрашивают большие площади. | Спокойнее интерфейс, выше различимость статусов. |
| 2 | Типографическая иерархия | Заголовок страницы 20 px, секции 14 px, основной текст 13 px, метаданные 11–12 px; uppercase только для коротких кодов. | Экран легче сканировать без увеличения высоты. |
| 3 | Двухуровневый shell | Глобальная панель 52 px и компактная строка проекта 46 px; активный раздел отмечен нижней линией, а не заливкой большой кнопки. | Больше места данным, понятнее текущий контекст. |
| 4 | Группировка без card wall | Связанные блоки объединяются общей поверхностью с разделителями; карточки остаются только для самостоятельных повторяемых сущностей. | Меньше визуального шума и вложенных рамок. |
| 5 | Единый ритм таблиц | Заголовок 36–40 px, компактная строка 48 px, строка с пояснением 62–88 px; sticky header, стабильные колонки и выравнивание чисел вправо. | Быстрее сравнение WBS, RAID и проектов без потери пояснений. |
| 6 | Иерархия экрана состояния | Сначала 4 KPI, затем две приоритетные колонки, ниже вторичные секции; счетчик встроен в заголовок, пустые блоки компактны. | Критичное видно в первом экране. |
| 7 | Синхронная верстка Гантта | Toolbar разбит на группы, дерево и шкала имеют общую высоту строк, выбранная строка подсвечивается целиком, текущая дата заметна без яркой заливки. | Проще сопоставлять задачу и полосу. |
| 8 | RAID как единая рабочая поверхность | KPI и матрица находятся в одной верхней полосе, фильтры встроены в заголовок реестра, детали раскрываются справа без сдвига таблицы. | Больше ширины реестру и меньше скачков верстки. |
| 9 | Состояния и переходы | Hover/focus 120 мс, раскрытие панели 180 мс, skeleton сохраняет геометрию, сохранение показывает локальный статус рядом с измененной строкой. | Интерфейс ощущается быстрым и не дергается. |
| 10 | Адаптивная композиция | На планшете скрываются вторичные колонки; на мобильном KPI становятся прокручиваемой горизонтальной лентой, приоритетные секции переходят в одну колонку. Макет фиксирует это на странице состояния; таблицы и Гантт требуют отдельной адаптивной спецификации. | Основной управленческий сценарий сохраняется на узких экранах без ложного обещания полной mobile-версии всех таблиц. |
